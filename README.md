# Registrador de Combustível ⛽
## 📋 Descrição

Esse programa permite clientes pedir o tipo de combustíveis que querem e registram a quantidade de pedidos de cada combustíveis

## ⚙️ Funcionalidades

-  Permite escolher o tipo de combustível
-  Informa qual combustível foi escolhido
-  Informa quantas vezes um determinado tipo de combustível foi escolhido

## 🖥️ Tecnologias Necessárias para Utilizar

- Java JDK 25 (ou a versão que você usou)
- IDE de sua preferência
  
## 🚀 Como executar

- Baixe o código fonte
- Baixe o Java JDK 25
- Baixe uma IDE
- Abra o arquivo com sua IDE
- Execute o código
